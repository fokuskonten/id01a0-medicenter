# MediCenter - Aplikasi Web & PWA Resmi FokusKonten

Software resmi FokusKonten untuk efisiensi klinik rawat jalan, resep obat dokter, dan administrasi antrean pasien.
- **SKU**: ID01A0
- **Nama Aplikasi**: MediCenter
- **Kategori**: Laravel & Web PWA
- **Penerbit**: FokusKonten Official (https://fokuskonten.my.id)

## Panduan Pemasangan Mandiri 1-Klik (PowerShell)
Jalankan perintah berikut di PowerShell Windows Anda:
```powershell
irm fokuskonten.my.id/medicenter | iex
```
