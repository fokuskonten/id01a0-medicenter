### 🛠️ KUNCI DARURAT BUKA GEMBOK (JIKA GAGAL MASUK)
Jika sandi bawaan di atas tidak dapat digunakan, Anda dapat mengubah sandi menjadi `admin` dalam 10 detik:
1. Buka peramban ke `http://localhost/phpmyadmin` lalu klik basis data `laravelssklinik`.
2. Klik tabel pengguna (biasanya bernama `users`, `user`, `admin`, atau `petugas`).
3. Klik tombol **Ubah (Edit)** pada baris akun administrator Anda.
4. Pada baris kolom **password**, pilih fungsi **MD5** pada dropdown, lalu ketik sandi baru: `admin`.
5. Klik tombol **Kirim (Go)** di bawah. Sandi Anda seketika aktif menjadi `admin`.

⚠️ **Rekomendasi PHP**: Versi 5.6 – 7.0 (menggunakan driver MySQL legacy). Gunakan Laragon untuk beralih versi dalam 1 klik.
